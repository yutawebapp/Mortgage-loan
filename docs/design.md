# 住宅ローンWebアプリ 設計書(ドラフト)

## 1. 目的・対象
- 対象: 一般個人(購入検討者)。会員機能なしの公開サイトから開始。
- 機能カテゴリと優先度

| カテゴリ | 優先度 | 概要 |
|---|---|---|
| 返済シミュレーター | P0 | 元利均等/元金均等、ボーナス併用、返済表 |
| 金融機関・商品比較 | P0 | 金利タイプ・手数料・団信で絞り込み/並び替え |
| 借り換え診断 | P1 | 残債・現行金利・諸費用から削減額と損益分岐点 |
| 借入可能額/審査目安 | P1 | 年収・既存借入から返済負担率で目安額 |

## 5. バックエンド方針
- 依存方向: controller → service → domain / mapper。計算ロジック(domain)は Spring/DB 非依存の純Java。
- 金額は BigDecimal。丸めは一元管理(仮置き: 円未満切捨て。要確定)。
- MyBatis: SQL は XML Mapper。動的条件は `<where>/<if>`。並び替えカラムは `${}` を使わず enum ホワイトリスト。
  `map-underscore-to-camel-case=true`。
- API: `/api/v1`、OpenAPI(springdoc)→ openapi-typescript で型生成。エラーは RFC 7807。入力値はログ出力しない。
- テスト: JUnit5 + Testcontainers(Postgres)。計算ロジックは外部の返済表と突合。

## 6. データ運用
- `rates` に `effective_from` と `source_url` を持たせ履歴保持。
- 更新は Flyway repeatable migration または CSV取込CLI。管理画面はP2以降。
- 画面に金利更新日と出典を必ず表示。30日超は警告表示を検討。
- 開発中の seed は架空データ。実在金融機関の金利を載せる場合は掲載可否を確認。

## 7. フェーズ
1. 雛形(Compose / Maven / Next.js / Flyway / healthcheck)
2. 返済シミュレーター
3. 商品比較
4. 借り換え診断

## 7.1 返済シミュレーター仕様(確定)
- 丸め: 円未満四捨五入(HALF_UP)。`common` の1か所で定義し、変更は1行。最終回で残債を精算して端数を吸収。
- ボーナス払い: 対応。`bonusAmount`(ボーナス返済分の借入額)を年2回(6, 12, 18…ヶ月目)で返済。
  通常分(月利=年利/12, 期間=年×12)とボーナス分(半年利=年利/2, 回数=年×2)を独立したローンとして計算し、ボーナス月は合算。
- 方式: 元利均等 / 元金均等。金利0%は元本÷回数。
- 入力範囲: 借入額 1〜10億円、年利 0〜20%、期間 1〜50年。

## 7.2 商品比較仕様(実装済み)
- rateType: VARIABLE / FIXED_FULL / FIXED_PERIOD(固定期間 3/5/10年)。sort: RATE_ASC(既定)/RATE_DESC/NAME_ASC(enumホワイトリスト、`${}`不使用)。
- 現在金利 = 各商品で `effective_from <= 今日` の最新行。詳細は手数料と金利履歴(新しい順)を返す。
- seed(V3)は架空データのみ。画面にサンプルデータ注記、30日超の未更新警告、免責を常時表示。

## 7.3 借り換え診断仕様(実装済み)
- `POST /api/v1/simulations/refinance`。現在ローン(残債・現行金利・残り期間)と借り換え後(新金利・新期間)を `RepaymentCalculator` で計算し比較。ボーナス併用なし。
- 諸費用は借り換え後ローンに含めず、手元から先払いと仮定。初期値は75万円(残債3,000万円の約2.5%。借入額の1.5〜3.0%が一般的な目安とされる仮置きで、公式値ではない。定率型と定額型の差を中間でとった値)。
- 累計損得 net(m) = 現行の累計返済 − 借り換え後の累計返済 − 諸費用。損益分岐月 = net が初めて0以上になる月(なければ null)。
- 返済期間が異なる場合、総額は異なる期間の比較になるため、画面に注意書きを出す。

## 7.4 借入可能額/審査目安仕様(実装済み・仮置き値)
- `POST /api/v1/simulations/eligibility`。返済負担率の上限: 年収400万円未満30% / 以上35%。審査金利は既定3.5%。
- 年間返済可能額 = 年収×上限 − 他の借入の年間返済額。月額 = 年額/12。借入可能額 = 元利均等の逆算(1万円単位で切り捨て)。審査金利と実際の金利の2通りを返す。
- 上限率・審査金利は目安の仮置き値。定数は `EligibilityCalculator` の1か所に集約。実際の審査基準は金融機関ごとに異なる旨を画面に常時表示。

## 7.5 住宅ローン控除シミュレーター(設計案・未実装)
決定事項: 独立ページ `/tax-deduction`。簡易入力。制度データはDBに入居年別で保持し、出典URLと確認日を表示。年末残高は借入条件から自動計算(繰上げ返済は対象外)。
控除額の上限(所得税+住民税)は年収から簡易推計する(独身・扶養なし・社会保険料率の仮置きで、安全側=控除額を多く見積もらない方向)。

### 制度データ(確認済み: 国交省 住宅ローン減税 Q&A 2026年7月更新、国税庁 タックスアンサー No.1211-1)
- 入居〜2030/12/31、控除率0.7%(一律)、合計所得2,000万円以下、返済期間10年以上、床面積は原則40㎡以上(合計所得1,000万円超 or 子育て上乗せ利用時は50㎡以上)。※国税庁ページは床面積が旧記載(50㎡)のため国交省を採用。
- 借入限度額(子育て世帯等の上乗せ) / 控除期間
  - 新築・認定住宅 4,500万(5,000万)/13年、新築・ZEH水準 3,500万(4,500万)/13年
  - 新築・省エネ基準適合 2026-27入居のみ 2,000万(3,000万)/13年。2028年以降は対象外(2027年末までに建築確認 or 2028/6/30までに建築なら2,000万/10年)
  - 新築・その他 対象外(2023年末までに新築された家屋のみ 2,000万/10年)
  - 中古・認定 3,500万(4,500万)/13年、中古・ZEH 3,500万(4,500万)/13年、中古・省エネ適合 2,000万(3,000万)/13年、中古・その他 2,000万/10年(上乗せなし)
  - 買取再販: 認定・ZEHは新築と同水準、省エネ適合・その他は中古と同水準
- 子育て世帯等 = 19歳未満の扶養親族あり or 夫婦いずれかが40歳未満(入居年12/31時点)。40㎡台は上乗せ対象外。
- 新築で2028年以降入居かつ災害レッドゾーンは対象外(注意書きで案内)。
- 控除額 = min(年末残高, 借入限度額) × 0.7%。1年目は確定申告、2年目以降は年末調整(説明のみ)。

### 税額推計の検証済みパラメータ(令和8年分・9年分。公式ページを直接確認)
- 給与所得控除(国税庁 No.1410, 令和8年4月1日現在法令): 〜220万円 74万円 / 〜360万円 収入×30%+8万円 / 〜660万円 収入×20%+44万円 / 〜850万円 収入×10%+110万円 / 850万円超 195万円。令和8年12月1日施行・令和8年分から適用。最低保障74万円のうち5万円は2年間(令和8・9年分)の時限措置。※660万円未満は本来「別表第五」の表で求めるため、式による値は近似(概算)。
- 所得税の基礎控除(国税庁 No.1199 + 財務省資料): 令和8・9年分は合計所得金額 〜489万円(給与収入665万円相当)=104万円 / 489万円超〜655万円(給与収入850万円相当)=67万円 / 655万円超〜2,350万円=62万円。令和10年分以後は別の額(物価連動で改定)。※表の結合セルを財務省資料の図と突き合わせて解釈した。将来年は「令和8・9年分の制度が続く前提」とする。
- 所得税の税率(国税庁 No.2260): 〜194.9万円 5% / 〜329.9万円 10%−97,500 / 〜694.9万円 20%−427,500 / 〜899.9万円 23%−636,000 / 〜1,799.9万円 33%−1,536,000 / 〜3,999.9万円 40%−2,796,000 / 4,000万円〜 45%−4,796,000(課税所得は1,000円未満切捨て)。復興特別所得税は税額の2.1%(平成25〜令和29年分)。令和9年以後は防衛特別所得税が創設され復興特別所得税の税率が下がるが、合計税率は変わらない。
- 個人住民税(総務省資料 令和8年5月29日): 所得割は一律10%、基礎控除は最高43万円(据え置き)、給与所得控除は所得税と同一(令和8年分所得に係る令和9年度分から)。
- 住宅ローン控除の住民税側の控除: 所得税から引ききれなかった額を翌年度の住民税から控除。上限は前年分の所得税の課税総所得金額等×5%(最高97,500円)。平成21年〜令和12年12月31日に居住した方が対象。総務省ページ https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/090929.html で確認済み(2026-11-17)。
- 仮置き(公式の値ではない): 社会保険料率15%(額面年収に対する割合、既定値)、調整控除は2,500円固定(単身・基礎控除差5万円×5%)。独身・扶養なし・他の所得控除なしの前提。
- 検証用の手計算例(令和8年分、社会保険料15%): 年収500万円 → 給与所得356万円、基礎控除104万円、課税所得177万円、所得税88,500円(復興特別所得税込み約90,300円)、住民税課税所得238万円、所得割235,500円、住民税側の控除上限88,500円。年収800万円 → 給与所得610万円、基礎控除67万円、課税所得423万円、所得税418,500円、住民税課税所得447万円、所得割444,500円、住民税側の控除上限97,500円。
- 公式で再検証が済んでいない数値はコードに埋め込まず、DBに「出典・確認日」つきで登録する。調査担当(explorer)の報告には誤りがあった(年収800万円の例で基礎控除62万円を使用=正しくは67万円、復興特別所得税の期間を令和37年と記載=正しくは令和29年、年収500万円の例は基礎控除104万円の根拠の説明が不正確)ため、上記は公式ページから直接確認し直した値。
- 推計手順: 給与所得控除 → 給与所得 → 社会保険料(仮置き率) と基礎控除 → 所得税(速算表×復興特別所得税) → 住民税(所得割10%、基礎控除、調整控除) → 住民税側の控除上限(所得税の課税総所得金額等×5%、最高9.75万円。※要検証)。
- 制度は年分で変わる(例: 所得税の基礎控除は令和8年分と令和10年分以後で異なる)。将来年は「現行制度が続く前提」と明記する。
- テスト: 国税庁の速算表・年末調整の表から手計算した期待値でゴールデンテストを作る(実装コードで期待値を作らない)。

## 7.6 住居費の総額シミュレーター(実装済み)
- `POST /api/v1/simulations/total-cost`、画面は `/total-cost`。制度の数値は使わず、保有コスト(管理費・修繕積立金・固定資産税等・保険料)はすべてユーザー入力。
- 諸費用 = 物件価格 × 諸費用の割合(既定10%、円未満四捨五入)。借入額 = 物件価格 + 諸費用 − 頭金。購入予算の逆算(7.5以前の budget)と同じく、諸費用は頭金と借入額を合わせた予算の中から支払う前提。
- 総額 = 頭金 + ローン返済額の合計 + 返済期間中の保有コスト。月平均 = 総額 ÷ (返済期間の月数)(四捨五入)。諸費用は借入に含まれるため、総額に二重には足さない。
- 保有コストは毎年同額。完済後の費用、売却価値、住宅ローン控除、将来の値上がりは含まない(notes で返す)。返済計算は `RepaymentCalculator`(ボーナス・繰上げなし)。

## 7.7 金利タイプの比較(実装済み)
- `POST /api/v1/simulations/rate-types`、画面は `/rate-types`。比べるのは VARIABLE_FLAT(変動・据え置き)/ VARIABLE_RISE(変動・上昇)/ FIXED_PERIOD(固定期間選択型)/ FULL_FIXED(全期間固定)の4ケース。金利はすべてユーザー入力の仮の値で、将来の金利は予測しない。
- 金利が変わるケースは、切り替え月まで元の金利で返済し、その時点の残債を残りの期間で新しい金利により再計算する簡易モデル(`RateRiseCalculator` と同じ考え方)。5年ルール・125%ルール、保証料・手数料・団信の違いは含まない。
- 固定期間選択型の終了後の金利は、開始時より低くても高くてもよい。全期間固定との総返済額の差を返す(順位づけや「有利/不利」の表現はしない)。

## 7.8 二人での借り入れ(ペアローン・収入合算)(第1段階: 借入可能額・住宅ローン控除)
- `common/BorrowerMode`: SINGLE / PAIR_LOAN(ペアローン)/ JOINT_DEBT(収入合算・連帯債務)/ JOINT_GUARANTEE(収入合算・連帯保証)。`/eligibility` と `/tax-deduction` が対応(リクエストに `mode` と partner 系の項目を追加。省略時は従来どおり単身)。返済シミュレーターは第2段階として負担割合ごとの表示に対応(7.11)。総コスト・購入予算は、ローンが合計額でも返済額が変わらないため未対応。
- **借り方の引き継ぎ**: `/simulation` は `pair=1` または `share=<1..99>`(あなたの負担割合)で「二人で借りる」をオンにして開く。借入可能額(ペアローン・連帯債務のとき `pair=1`)と住宅ローン控除(同じく、負担割合があれば `share`)の「返済額を試算する」リンクが付ける。ローカル保存はしない。
- **2つのプランの比較**(`/simulation`): 「別の条件と比べる」でプランB(金利・返済期間・返済方式。借入額とボーナス設定はプランAと共通)を開き、毎月の返済額・総返済額・利息総額・期間を、差(B−A)の数値だけで並べる。「有利/不利」などの判定は出さない。保存・CSVの対象外(印刷には含む)。
- **完済時の年齢**(`/simulation`): 任意入力の現在の年齢(18〜80)に返済期間を足した「完済時の年齢の目安」を表示する。判定は出さず、金融機関ごとに上限があることだけ注記する。保存しない。
- 借入可能額: JOINT_DEBT = 二人の収入・他の借入を合算して1本として審査。JOINT_GUARANTEE = 本人の収入 + 保証人の収入×割合(既定50%、切り捨て。金融機関で異なる仮置き値)。PAIR_LOAN = 各人を別々に審査して合計(各人1万円単位で切り捨てた額の和)。
- 住宅ローン控除: PAIR_LOAN と JOINT_DEBT は、借入額を負担割合(既定50%、持分と同じ前提)で分け、`TaxDeductionCalculator` を人ごとに実行して合算。借入限度額・合計所得金額の判定・子育て世帯等の区分は人ごと(借入限度額を人ごとに適用する点は公式資料で明確に確認できていない前提)。床面積は建物全体で判断(持分で按分しない)。JOINT_GUARANTEE は保証人を債務者としないため、控除は本人のみ。
- 出典(確認済み): 国交省 住宅ローン減税 Q&A 2026年7月更新(ペアローン・連帯債務の合計所得金額は1人ずつ判断、子育て世帯・若者夫婦世帯は申請者ごと)https://www.mlit.go.jp/jutakukentiku/house/content/002011976.pdf / 国税庁 質疑応答事例 共有の家屋を連帯債務により取得した場合の借入金の額の計算 https://www.nta.go.jp/law/shitsugi/shotoku/06/36.htm / 国税庁 No.1213 注1(4)(床面積は共有持分を乗じない)https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1213.htm

## 7.9 マイホームと賃貸の比較(実装済み)
- `POST /api/v1/simulations/rent-vs-buy`、画面は `/rent-vs-buy`。結論(どちらが得か)は示さず、入力した前提のもとで累計支出がどう推移するかを並べる。すべて利用者の仮定値で、制度の数値は使わない。初期値は中立(物件価値の変化・家賃の上昇・売却費用・更新料・初期費用はすべて0)。
- 購入の累計支出 = 頭金 + ローン返済額の合計 + 保有コスト(管理費・修繕積立金・固定資産税等・保険。完済後も続く)。諸費用は頭金と借入額を合わせた予算の中から支払う前提(7.6と同じ)。実質負担 = 累計支出 − (想定の物件価値 ×(1 − 売却費用割合) − ローン残高)。賃貸の累計支出 = 初期費用 + 家賃(年上昇率)+ 更新料。
- 「初めて下回る年」= 購入の指標が賃貸の累計以下になる最初の年(その後に逆転する場合は考慮しない)。物件価値の変化率を ±2 ポイント変えた3ケースを感度表として返し、結果が前提にどれだけ左右されるかを示す。
- 含まないもの: 住宅ローン控除、差額の運用益、同じ条件の住まいかどうか、将来の価値の予測。

## 7.10 ライフプラン(家計の見通し)(実装済み)
- `POST /api/v1/simulations/life-plan`。現在の年齢から想定の最終年齢(既定95歳、最終年齢を含む)までを1年ごとに、収入・生活費・住宅ローン返済・住居費・子どもの教育費・貯蓄残高を並べる。**全額を今日の円で表示し、物価・賃金の変化は考慮しない**。「OK/NG」などの判定は出さず、数字のみ返す。
- 収入: 退職年齢未満は手取り年収 ×(1+成長率)^j(四捨五入)、年金等は年金開始年齢から。生活費は現役期と退職後で別入力(月額×12)。
- 住宅ローン: `RepaymentCalculator.singleLoanSchedule`(ボーナスなし)。住居費(管理費・修繕積立金 ×12 + 固定資産税・保険)は、ローン完済後も毎年かかる。
- 教育費: 子の年齢 = 現在の年齢 + j。3〜17歳は学校の種類(公立/私立)別の年額(文部科学省「令和5年度子供の学習費調査」表2の学年別学習費総額)、18〜21歳は大学の授業料(国立/私立)(1年目は18歳)。進路は ALL_PUBLIC / PRIVATE_HIGH(高校のみ私立)/ PRIVATE_JUNIOR_AND_HIGH(中学・高校が私立)/ ALL_PRIVATE。0〜2歳の子は学校費用なし。
- 貯蓄: 年初残高に対する運用益(正の残高のみ、四捨五入)→ 収支を加算。初年度に頭金・諸費用(upfrontPayment)を貯蓄から支払う。
- 教育費・学費の数値は DB(Flyway V6: `education_costs` / `university_costs`)に出典URL・確認日つきで持ち、コードに埋め込まない。国立大学は標準額(初年度は入学料を含む)、私立大学は文部科学省「私立大学等の令和7年度入学者に係る学生納付金等調査結果」の平均(学費のみで仕送り等は含まない。入学料・施設設備費・実験実習料を含み、2年目以降は入学料・その他を除く仮定)。完済時の年齢が想定の最終年齢を超えるときは、`loanPayoffAge` は null を返し、返済額の合計は期間内の分だけになる。
- 含まないもの: 仕送り・通学費・一人暮らし費用、ボーナス、税・社会保険料の推計、年金額の推計(入力値)、教育費の物価上昇、個別の家計事情。教育費は全国平均で個人の値ではない。
- 注記(notes)は常に全件返す。summary.minSavings / minSavingsAge は年末残高の最小値、firstShortfallAge は年末残高が初めて0円未満になる年齢。

## 7.11 ツール横断の体験改善(実装済み)
- **共有条件**: 借入額(万円)・金利・返済期間の3項目だけを、ブラウザの localStorage(キー `mortgage-loan.sharedConditions.v1`)に保存し、各ツールの初期値に使う。優先順位は URL クエリ > 保存値 > ツールの既定値。意味が同じ項目にだけ対応づけ(例: 物件価格の欄に借入額は入れない)。サーバーには送らず、画面に「この端末のブラウザにだけ保存」と消去ボタンを出す。ロジックは `lib/sharedConditions.ts`、フックは `lib/useSharedConditions.ts`。
- 保存するのは、利用者が自分で編集した項目だけ(URLや既定値は保存しない)。保存値を入れたときは「前回入力した○○を入れてあります」と通知し、保存値があるときだけ消去ボタンを出す。
- **条件のURL共有**: 返済シミュレーター・繰上げ返済・金利上昇は「この条件のリンクをコピー」、住居費の総額・マイホームと賃貸の比較は「主な条件(物件価格・金利・期間)」のリンクをコピー。主な入力を運べない画面(年収などが主入力の借入可能額・購入予算・住宅ローン控除など)にはボタンを置かず、年収はURLに載せない。
- **次に調べる**: 結果欄に、条件を引き継いだ次ツールへのリンクを最大3件。リンクは重複を避け、以下の流れに限る: 返済シミュレーター → 繰上げ返済 / 金利上昇 / 住居費の総額、購入予算 → 住居費の総額 → マイホームと賃貸の比較 → ライフプラン、住居費の総額 → 住宅ローン控除、繰上げ返済 → 借り換え、金利上昇 → 金利タイプの比較。
- **返済予定表の出力**: `/simulation` で表示中の年別・月別の表を CSV(UTF-8 BOM・CRLF)で保存、または印刷できる。印刷物と CSV の先頭には、試算した条件(借入額・金利・期間・方式・ボーナス・負担割合)と試算日、「目安」の注記を、結果を出したリクエストの値で付ける。
- **二人で借りる場合の返済額**(7.8 第2段階、`/simulation` のみ): `POST /api/v1/simulations/repayment` に任意の `selfSharePercent`(1〜99)を追加。借入額(ボーナス分も)を四捨五入で負担割合に分け(相手側は残り)、それぞれを別のローンとして `RepaymentCalculator` で計算し `pairBreakdown`(self / partner)で返す。注記コード `PAIR_SHARE_PROVISIONAL`。実際のペアローン・連帯債務の扱いは金融機関で異なり、二人の合計は円未満の四捨五入で全体の計算と数円ずれることがある。総コスト・購入予算は未対応。

## 7.12 入力欄の初期値(統一・実装済み)
- 共通の既定値は `frontend/src/lib/defaults.ts` に置く。借入額 4,000万円 = 物件価格 4,000万円 × (1 + 諸費用10%) − 頭金 400万円 が成り立つように揃える。
- 共通: 借入額 4,000万円 / 金利 1.2% / 返済期間 35年 / 年収 500万円 / 物件価格 4,000万円 / 頭金 400万円 / 諸費用 10% / 返済方式は元利均等 / 購入予算の毎月の返済額 11.7万円(4,000万・1.2%・35年の毎月返済額 116,680.9円 ≈ 11.7万円)。
- 保有コストの既定値(仮置き・マンション想定): 管理費 12,000円/月、修繕積立金 17,000円/月、固定資産税・都市計画税 200,000円/年、火災・地震保険料 24,000円/年。根拠は国交省「令和5年度マンション総合調査」(管理費平均 約11,500円、修繕積立金平均 約13,000円/月)と「修繕積立金ガイドライン」(令和6年6月改定、252円/㎡・月 × 約70㎡ ≈ 17,600円)、標準税率(固定資産税1.4%・都市計画税0.3%)、保険は損害保険料率算出機構等の目安。公式の計算値ではなく地域・構造で大きく変わる。戸建てでは管理費を0にする。ライフプランの住居費の初期値はこれを合算した毎月29,000円(管理費+修繕積立金)・毎年224,000円(固定資産税等+保険)。定数は `lib/defaults.ts`。
- 住宅ローン控除の既定の住宅性能は「認定住宅（長期優良住宅・低炭素住宅）」(`CERTIFIED`)。新築・2026年4月入居・借入4,000万円なら認定住宅の新築限度額4,500万円の内側に収まり、借入額が限度額で頭打ちにならない。
- ツール固有で共通値と違う値: 借り換え(現在の残債 3,000万円、現行金利 1.5%、新金利 1.0%、残存・新期間 30年、諸費用 75万円 — 残債の約2.5%の仮置き。ローンに含めるかは別途検討)、金利タイプの比較の固定金利(固定期間 1.4% / 終了後 2.0% / 全期間固定 1.8%)、住宅ローン控除の配偶者の年収(300万円)、ライフプランの手取り年収(400万円、年収500万円の手取りの仮の目安。公式の計算値ではない)・貯蓄・家族関連、審査金利・返済負担率・賃貸比較の分析期間。
